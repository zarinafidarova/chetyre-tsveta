# Четыре цвета

Сетевая карточная игра по правилам, знакомым по УНО, на 2–10 человек.
Фронтенд на React (Vite), бэкенд на Go, связь через WebSocket.

Сайт: https://uno.brayan-train.ru

## Как устроено

```
браузер (React) ──WebSocket /ws──► Go-сервер
                                     ├─ hub.go   столы, игроки, рассылка состояния, боты
                                     ├─ game.go  правила: колода, ходы, +2/+4, разворот, штрафы
                                     ├─ chat.go  чат стола: история, защита от спама
                                     ├─ ws.go    WebSocket на стандартной библиотеке
                                     └─ main.go  HTTP: /ws и статика из web/dist
```

- Сервер хранит всё состояние и проверяет каждый ход. Клиент только показывает то, что прислал сервер.
- Каждый игрок получает только свои карты; про соперников приходит лишь количество карт.
- После перезагрузки страницы игрок возвращается за свой стол (код и секрет лежат в localStorage).
- Если игрок пропал больше чем на 2 минуты, он встаёт из-за стола, а его карты уходят под колоду.
- Столы хранятся в памяти: перезапуск сервера их сбрасывает. Для дружеской игры этого достаточно.
- У Go-части нет внешних зависимостей, `go.mod` пустой.

## Запуск

Нужны Go 1.22+ и Node 18+.

```bash
# 1. Собрать фронтенд
cd web
npm install
npm run build        # появится web/dist
cd ..

# 2. Запустить сервер
go run .             # http://localhost:8080
```

### Разработка

Два терминала:

```bash
go run .                 # бэкенд на :8080
cd web && npm run dev    # фронтенд на :5173 с горячей перезагрузкой, /ws проксируется на :8080
```

## Первый запуск на сервере

Нужны git, Go 1.22+, Node.js 18+ и nginx. Проверить: `go version`, `node -v`.

```bash
# 1. Код (для приватного репозитория добавь серверу deploy key на GitHub)
git clone git@github.com:zarinafidarova/chetyre-tsveta.git /var/www/chetyre-tsveta

# 2. Сборка и запуск игрового сервера (служба uno ставится сама)
bash /var/www/chetyre-tsveta/deploy/update.sh

# 3. nginx
cp /var/www/chetyre-tsveta/deploy/nginx/uno.brayan-train.ru.conf /etc/nginx/sites-available/
ln -s /etc/nginx/sites-available/uno.brayan-train.ru.conf /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# 4. HTTPS
certbot --nginx -d uno.brayan-train.ru
```

Если на сервере нет `sites-available`, положи конфиг в `/etc/nginx/conf.d/` вместо шагов с `cp` и `ln`.

Где что живёт на сервере:

- `/var/www/chetyre-tsveta/web/dist` — собранный фронт, его отдаёт nginx;
- `/var/www/chetyre-tsveta/bin/uno-server` — игровой сервер, слушает `127.0.0.1:8095`;
- служба `uno`: `systemctl status uno`, логи `journalctl -u uno -f`.

## Обновление

Запушь изменения в `main`, потом на сервере:

```bash
bash /var/www/chetyre-tsveta/deploy/update.sh
```

Скрипт сам подтянет код, соберёт фронт и сервер и перезапустит службу. Столы хранятся в памяти,
поэтому перезапуск обрывает идущие партии; если менялся только фронт, сервер не перезапускается.
Если новая версия сервера не поднялась, скрипт вернёт прошлую.

## Протокол

Клиент → сервер: `hello`, `create`, `join`, `addbot`, `kick`, `start`, `play`, `draw`, `pass`, `skip`, `leave`, `chat`.
Сервер → клиент: `state` (всё, что нужно для отрисовки), `joined`, `home`, `error`, `chat`, `chatHistory`.

Чат живёт вместе со столом: новый игрок получает последние 60 сообщений, писать можно не чаще раза в 0,4 секунды,
длина сообщения до 300 символов.

## Картинки на картах

Положите файлы в `web/public/cards/`:

| Файл | Карты |
|---|---|
| `blue.png` | синие |
| `red.png` | красные |
| `yellow.png` | жёлтые |
| `green.png` | зелёные |
| `wild.png` | «дикие»: заказ цвета и +4 |

Картинка обрезается по центру под окно карты, лучше всего подходят квадратные от 500×500.
Если файла для какого-то цвета нет, карты этого цвета рисуются без картинки.
После добавления файлов пересоберите фронт (`npm run build`).

## Карты

Карты нарисованы на CSS и SVG, картинок в проекте нет (`web/src/Card.jsx` и раздел «карты» в `styles.css`).
У каждого цвета свой узор: красный — зигзаг, жёлтый — лучи, зелёный — крапинка, синий — волны.
Особые карты (пропуск, разворот, +2, +4, заказ цвета) получили свои иконки, у «диких» карт вращается радужная рамка.
Подробности в комментарии в начале `hub.go`.
